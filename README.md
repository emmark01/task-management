# Northwood

A React task-management workspace with a board, list, calendar, projects, team, and settings.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. Use **Enter workspace** on `/login` to reach the cabin.

## What’s inside

- Dashboard with due work and a trail log
- Drag-and-drop kanban board
- Filterable task list
- Project cards, month calendar, and team directory
- Local UI state for creating, moving, and commenting on tasks
